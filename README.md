# Introduction
This project is a Visual Studio 2026 console application that targets .NET 10. It may be run on Windows 10 or later or on Linux.

The purpose of this application is to generate audio SIP calls and to deliver one or more calls to a system under test. It receives audio media from the system under test and it calculates various call quality statistics. This application sends audio from a fixed pre-recorded file.

This application can be used for load testing of both the network and the system under test if the system under test is capable of answering and managing multiple calls automatically. One such application is the [PSAP Simulator](https://github.com/PhrSite/PsapSimulator) application.

This application provides a browser based graphical user interface. The user starts the console application and then connects to it via a browser. It has been tested with the Microsoft Edge and Google Chrome browsers.
