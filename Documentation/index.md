# The CallLoadTester Application
This application is a test program for performing SIP call load testing by sending multiple calls to a system under test.



Please refer to the [Operators Manual](docs/GettingStarted.md) for instructions on how to install and use this application.

This is an open source project. The GitHub repository is called [CallLoadTester](https://github.com/PhrSite/CallLoadTester).
