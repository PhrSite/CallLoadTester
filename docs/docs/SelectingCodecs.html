    Selecting Audio and Video Codecs

    The Codec Selection dialog box allows the user to select which audio or video codecs are offered when audio or video media is offered in an INVITE request. The title bar of this dialog box indicates the media that the dialog box is being used for.

    The codec names shown in the "Selected" list box are the ones that will be offered. The codec names in the "Available" list box are the ones that can be added to "Selected" list box.

    This dialog box also allows the user to select the order in which codes are offered in an INVITE request. The order shown in the Selected list is the order that the codecs will appear in the SDP contents of the INVITE request.

    To add an available codec to the selected list, select the codec in the Available list and click on the "<<<" button.

    To remove a selected codec from the Selected list, select the codec in in the Selected list and click on the ">>>" button.

    The Clear button clears the Selected list.

    At least one codec name must be selected.
